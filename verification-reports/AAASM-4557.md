## Acceptance criteria

### ✅ AC1 — Quick-start Step 1 renders as a pnpm/npm/yarn Tabs switcher generated by `scripts/generate-docs-metadata.mjs`

* `docs/02-quick-start/index.md` "1. Install" is a machine-generated block
  (`{/* GENERATED BY scripts/generate-docs-metadata.mjs — DO NOT EDIT. Block:
  install-commands. */}`) emitting `<Tabs groupId="quickstart-install-package-manager">`
  with three `<TabItem>`s — `pnpm` (default), `npm`, `yarn` — each showing only
  its own command. `Tabs`/`TabItem` are imported at the top of the file
  (shared with the existing framework tabs in section 3).
* The built current/"next" page confirms the switcher renders — three Infima
  tab buttons, pnpm active by default, each command present:

```
$ QS=website/build/next/quick-start/index.html
$ grep -oE 'class="tabs__item[^"]*"[^>]*>(pnpm|npm|yarn)' "$QS"
class="tabs__item tabItem_sTcH tabs__item--active">pnpm
class="tabs__item tabItem_sTcH">npm
class="tabs__item tabItem_sTcH">yarn
$ grep -o 'pnpm add @agent-assembly/sdk\|npm install @agent-assembly/sdk\|yarn add @agent-assembly/sdk' "$QS" | sort -u
npm install @agent-assembly/sdk
pnpm add @agent-assembly/sdk
yarn add @agent-assembly/sdk
```

* The switcher lands on the current/unreleased version (`docs/` → `build/next/`),
  which is correct: the released `0.0.1-rc.4` snapshot under
  `website/versioned_docs/` is intentionally left as-is (see AC-scope note).

### ✅ AC2 — Tab-title font-size is visibly smaller/tighter than body text, sitewide

* `website/src/css/custom.css` adds a single global rule
  `.tabs__item { font-size: 0.85rem; }` — `.tabs__item` is Infima's class for
  every `<Tabs>` tab button, so the override applies to all `<Tabs>` usages,
  not just quick-start. Body text is `--ifm-font-size-base` (17px), so tab
  titles read as UI chrome rather than body copy.
* Present in the compiled CSS asset:

```
$ grep -rho 'tabs__item{font-size:.85rem}' website/build/assets/css/*.css
tabs__item{font-size:.85rem}
```

### ✅ AC3 — `docs/api/**` and `docs/superpowers/specs/*.md` no longer appear in the built sidebar

* `website/docusaurus.config.ts`'s content-docs `exclude` list now includes
  `"api/**"` and `"superpowers/**"` (alongside the classic-preset defaults,
  which must be repeated because setting `exclude` overrides rather than
  extends them), so neither path can be picked up by the autogenerated sidebar
  (`sidebars.ts` uses `dirName: "."`).
* Neither path exists in `master`'s tracked tree (both were local-only
  artifacts — see [AAASM-4556]); the exclude is the defensive fix so they can
  never leak in from a contributor's local checkout. The built site contains
  no such pages:

```
$ find website/build -type d -name superpowers | wc -l
0
$ find website/build -path '*/api/*' -name '*.html' | grep -v api-reference | wc -l
0            # the real API reference (06-api-reference) is unaffected
```
